## Реализация

**src/main.jsx и src/data.js**. Точка входа монтирует App в StrictMode. data.js содержит неизменяемые исходные задачи и справочник категорий. Используется готовая инфраструктура преподавателя.

**src/App.jsx**. Владеет tasks, filters и editingId. Видимая выборка и статистика вычисляются на каждом рендере. Обработчики используют функциональное обновление setTasks. Следующий id — максимум полного массива плюс один. Подтверждение удаления выполняется до обновления состояния.

**src/domain/task-service.js**. Чистые функции проверяют черновик, фильтруют по четырём условиям через И и вычисляют статистику полного набора. addTask проверяет id, updateTask сохраняет completed и id, toggleTask инвертирует статус, removeTask удаляет по id. Входные массивы не изменяются.

**src/components/TaskForm.jsx**. Управляемая форма хранит draft и errors через useState. noValidate позволяет показать собственные ошибки. При успехе onSave возвращает true и форма очищается, при false черновик остаётся. key={editingId ?? "new"} в App пересоздаёт форму при выборе другой записи.

**src/components/TaskFilters.jsx**. Четыре управляемых поля передают новый объект фильтров наверх. completed хранится строкой и сравнивается явно. Сброс устанавливает четыре пустые строки.

**src/components/TaskList.jsx и TaskItem.jsx**. Список получает уже отфильтрованные задачи и использует стабильный key=task.id. Карточка показывает статус, приоритет и категорию и сообщает о действиях через callbacks. JSX выводит название как текст.

**src/components/TaskStats.jsx и src/variant.js**. Статистика относится ко всему массиву, а найденное количество — к выборке. Вариант 8 включает невыполненные задачи высокого приоритета категории 2.
