## Реализация

**src/App.jsx и components**. Готовый интерфейс преподавателя связывает фильтры, форму и список с useTaskData. Форма ожидает Promise<boolean>, сохраняет черновик при ошибке. Снимок редактируемой записи не пропадает при смене фильтров. Во время изменения и неуспешного GET изменяющие действия отключены.

**src/hooks/useTaskData.js**. Реализованный хук хранит snapshot, status, error, mutationError, pending и revision. Эффект зависит от api, четырёх полей фильтров и revision. Каждая загрузка вызывает loadInitialData, получает свой AbortController и active. Cleanup помечает ответ неактуальным и отменяет запрос. Старый успех и ошибка игнорируются; последний успешный снимок при ошибке сохраняется.

**src/hooks/useTaskData.js функция mutate**. Ref немедленно блокирует повторную операцию до первого await. Отдельный контроллер отменяет мутацию при размонтировании. Успех возвращает true и увеличивает revision, вызывая GET с актуальными фильтрами. Ошибка записи сохраняется отдельно от ошибки чтения. finally освобождает только собственную блокировку. Смена фильтров не отменяет запись.

**src/config.js api-client.js task-api.js**. Готовые модули задают стабильный API и абсолютный адрес, выполняют HTTP и проверяют ответы. Сервер хранит данные в памяти. Повторный POST автоматически не выполняется.

**src/variant.js и api**. Включён вариант 8. Его сценарий: POST подходящей задачи, GET, PATCH completed=true, GET. Запись сначала появляется, затем исчезает из отфильтрованной выборки.
