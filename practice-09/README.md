## Реализация

**src/server.js и src/app.js**. Предоставленная инфраструктура отделяет открытие порта от фабрики приложения. app.js устанавливает CORS, no-store, nosniff, отвечает на OPTIONS, подключает маршруты и обработчик ошибок последним.

**src/validation.js**. parsePositiveId принимает только полную строку положительного целого без ведущих нулей и проверяет Number.isSafeInteger. parseFilters отклоняет неизвестные и повторные query-параметры, явно преобразует true/false, проверяет приоритет и categoryId, обрезает q и ограничивает длину 100.

**src/task-service.js**. selectTasks объединяет условия через И и использует toLocaleLowerCase для поиска. Ограничение отсутствует при null, поэтому false не теряется. findTask ищет по id и возвращает null при отсутствии.

**src/store.js и src/data.js**. Хранилище создаёт отдельные копии исходных данных для приложения. Маршруты обращаются к store, не импортируют исходный массив напрямую.

**src/routes.js**. GET health, categories, tasks и tasks/:id возвращают JSON. Список содержит meta.total и нормализованные filters. Неправильный id даёт 400, отсутствующая задача 404 с details.id. Остальные методы известных путей дают 405 и Allow. HEAD поддерживается GET-маршрутами Express.

**src/errors.js**. Готовый ApiError и middleware формируют единый JSON ошибки. Неожиданное исключение даёт INTERNAL_ERROR без раскрытия стека. Сервер ПР9 реализует только чтение; изменение данных относится к следующей работе.
