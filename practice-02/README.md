## 4. Модель данных и функции

Задача содержит положительный безопасный целочисленный `id`, очищенное название длиной 1–100, логический `completed` и приоритет `low`, `medium` или `high`. `data.js` хранит наборы, `task-service.js` — девять функций без вывода и глобального состояния, `main.js` — два демонстрационных сценария.

- При успехе создание возвращает `{ ok: true, task }`, операции — `{ ok: true, tasks }`.
- Ожидаемый отказ возвращается как `{ ok: false, error }`, не как необработанное исключение.
- `id` не равен индексу: после удаления позиция меняется, а идентификатор записи сохраняется.
- `getTaskStats` возвращает числовой процент, чтобы округление оставалось ответственностью вывода.
- При обновлении создаются новый массив и новый объект изменяемой задачи; неизменённые объекты можно использовать повторно.
